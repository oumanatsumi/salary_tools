# 💰 薪资小组件 (Salary Widget)

小米15 / 澎湃OS 3.0 桌面小组件 — 实时显示今天赚了多少，缓解上班怨气。

## 功能特性

- 📊 **实时显示今日收入** — 每30秒刷新一次，看着钱一秒秒增长
- ⚙️ **灵活配置** — 支持税前/税后月薪，支持固定金额或比例模式计算五险一金
- 🕐 **智能午休处理** — 午休时段收入暂停增长，午休结束后继续累计
- 📱 **4x2 桌面小组件** — 深色 AMOLED 友好设计，省电美观
- 🔋 **澎湃OS 优化** — 针对小米 HyperOS 电池管理做了专项适配

## 技术栈

- **Kotlin** + **Jetpack Compose** (设置界面)
- **Jetpack Glance** (桌面小组件)
- **WorkManager** (15分钟保底更新)
- **AlarmManager** (30秒高频更新)
- **DataStore** (设置持久化)

## 计算逻辑

```
日薪 = (月薪 - 五险一金) / 21.75
时薪 = 日薪 / 有效工作小时
每秒收入 = 时薪 / 3600
当前收入 = 每秒收入 × 已工作秒数
```

## 构建与运行

1. 用 Android Studio 打开 `E:\proj\salary-tools`
2. 等待 Gradle 同步完成
3. 连接小米15手机或启动 API 35 模拟器
4. 点击 Run 运行
5. 在桌面长按添加小组件 → 选择"今日已赚"

## 澎湃OS 使用说明

安装后请务必完成以下设置，否则小组件可能停止更新：

1. **关闭电池优化** — 设置 → 应用管理 → 找到"薪资小组件" → 电池 → 不限制
2. **开启自启动** — 安全中心 → 权限管理 → 自启动管理 → 允许
3. **锁屏清理白名单** — 电池 → 锁屏清理 → 将应用加入白名单
